The Markdown plugin provides source editing, live preview and reading surfaces for Markdown notes. It also connects supported metadata, panels and embeds to the workspace.

## Choose a view

Open a `.md` note with Markdown enabled. Use source when you want to edit the literal text, live preview to work with rendered formatting as you type, and reading view to read the document. Available actions depend on your build's editor associations.

Start with [Markdown basics](/help/editing/markdown-basics/) and [links and embeds](/help/editing/links-embeds-and-tags/). Rendering an embedded plugin view requires that plugin too: installing Markdown alone does not supply Bases, PDF or executable Notebook behavior.

Markdown is part of the reviewed shared default profile and remains user-disableable. Host builds can change the installed profile.
