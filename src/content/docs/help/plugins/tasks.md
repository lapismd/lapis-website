Markdown checklists work in ordinary notes without the standalone Tasks plugin. The current host profile can load Tasks for indexing and queries; that does not imply that standalone Tasks workspace views are available.

## Current boundaries

The legacy site advertised Kanban, Fizzy, calendars, and agenda views as available in every host. Those claims do not describe the current Desktop integration. Check the [Tasks repository](https://github.com/lapismd/lapis-plugin-tasks) and your build's plugin settings for supported workflows and release status.

Keep task content in Markdown and frontmatter. Enable only installed plugins that are compatible with your host and package versions.
