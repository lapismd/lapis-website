The shared Community plugin package is private and parked in the reviewed source inventory. It is not listed in the reviewed public catalog and has no supported installation path on this site.

This package is separate from the host's [community-plugin browser and installation workflow](/help/plugins/community-plugins/). A host can support installing community plugins without shipping this parked Community package.

Check your build's plugin management settings for supported installation features. Do not treat a source directory or an old screenshot as evidence that a Community workspace plugin is available.

## Source and availability

[Owning source](https://github.com/lapismd/lapis-plugins/tree/main/packages/community). Check [plugin availability](/help/plugins/core-plugins-overview/) and your build's installed plugin list before following this guide.
