description: The parked Sync package is separate from Nostr Sync.

The shared package with runtime ID `sync` is private and parked. It is not listed in the reviewed public catalog and this site provides no installation instructions for it.

The experimental [Nostr Sync preview](/help/plugins/nostr-sync/) uses a different package and runtime ID. Installing or copying the parked package is not a supported way to enable that preview.

Keep an independent vault backup and use the storage or synchronization workflows explicitly supported by your host. This status page does not promise an available built-in synchronization service.

## Source and availability

[Owning source](https://github.com/lapismd/lapis-plugins/tree/main/packages/sync). Check [plugin availability](/help/plugins/core-plugins-overview/) and your build's installed plugin list before following this guide.
