Docs adds `.doc.md` notes, books, a navigation sidebar and study cards. It is a separately versioned plugin with public source; it was not listed in the reviewed public plugin catalog. Use it only where your host provides a compatible installation.

## Find your documents

In a host with Docs installed, use **Open docs** to open its document sidebar. The default document root is `docs`; check the plugin settings if your vault uses a different location. Keep document content in the vault so it remains available as files.

## Study with cards

Use **Open cards** to inspect basic and cloze cards. The **Review due cards (note)** and **Review due cards (workspace)** commands choose the review scope. Scheduling uses FSRS. Supported Anki import can bring existing study material into the Docs workflow; review the import results before relying on them.

Command availability depends on the installed version. A public npm package does not imply that every Desktop preview bundles it.
