---
title: First-party plugins
description: Understand bundled and optional plugin availability.
---

First-party plugins are independently versioned. The installed Desktop or web profile determines which ones are bundled, installed, enabled, or unavailable; a published package is not proof that every host ships it.

## Start with your build

Open Settings and review the installed plugin list. Editing, Search, Graph, and file navigation use the current Notes framework and plugin packages. [Canvas](/help/plugins/canvas/), [Bases](/help/plugins/bases/), [PDF](/help/plugins/pdf/), and [Slides](/help/plugins/slides/) have their own package and host requirements.

[Notebook](/help/plugins/notebook/) is a separately installed executable-notebook plugin. [Tasks](/help/plugins/tasks/) currently has indexing/query integration without the legacy collection of workspace views. Terminal requires an admitted native host service; the browser cannot grant that service itself.

Screenshots demonstrate their named source plugin or Desktop scene. They do not imply those plugins are included or enabled in every preview build.
