CSV opens `.csv` and `.tsv` files as structured data. The first row supplies column headers; quoted delimiters and multiline values are retained.

## Work with a data file

Open a CSV or TSV file with the plugin enabled. The current source defaults to its canvas presentation; table and source modes are also available. Use the table for cell and header edits, sorting, and find/replace. These actions write through to the file, so keep a backup before making broad changes to important data.

Switch to source when you need to inspect the delimited text. The source presentation retains the file's lines rather than treating the data as a Markdown table. Supported note embeds can display CSV content inside another note.

The installed version determines the available modes. This is an editable data view, rather than a spreadsheet formula engine.
