CV Roles is a source preview for organizing roles, CVs and applications. The reviewed source uses runtime ID `roles` and stores role records under `Roles/<slug>/role.md`.

## Availability

No publicly accessible package, source repository or catalog installation was confirmed during the November 13 review. There is no general download or installation link here. A host that explicitly includes this preview may expose its Roles, CV and Applications views.

Keep the role Markdown files in the vault and follow the instructions for that particular host preview. Do not rename the `Roles` tree as part of a plugin/package rename or assume another build supports the same workflow.

See [plugin availability](/help/plugins/core-plugins-overview/) for generally catalog-listed alternatives and host boundaries.
