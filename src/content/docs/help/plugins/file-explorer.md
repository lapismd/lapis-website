---
title: File Explorer
description: Browse vault files and folders in the workspace.
---

File Explorer supplies the workspace file tree. It belongs to the reviewed shared default profile, alongside Markdown, Source Editor and Search; each remains user-disableable.

## Navigate a vault

Open the Explorer sidebar and expand a folder to find a file. Select a file to open it in the workspace. Available file and folder actions operate on the current vault, so review the selected path before renaming or deleting content.

The file's editor association and installed plugins determine how it opens. For example, a Markdown note can use Markdown views while an optional PDF plugin provides a PDF reader.

If Explorer is missing, check the sidebar layout and installed plugin settings. Its runtime ID is `lapis-file-explorer`; it is maintained in Notes rather than the shared plugin repository.
