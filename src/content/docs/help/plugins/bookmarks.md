Bookmarks provides a sidebar for frequently used files, folders and saved searches. Groups let you organize shortcuts without rearranging the vault.

## Keep a useful shortcut

Enable Bookmarks in a compatible host and open its sidebar. Use the bookmark actions for the file, folder or search you want to revisit, then organize related entries into groups. Selecting a bookmark returns to that location or search.

A bookmark is a shortcut to existing content. Keep the underlying files in the vault and use normal file operations to manage them. If an entry no longer opens, check whether its target was moved or removed.

Bookmark availability and sidebar placement depend on your installed plugin profile.
