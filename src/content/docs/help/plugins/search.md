Search is the vault-wide retrieval surface for notes, metadata, and supported
plugin content.

## What Search covers

- Markdown note content
- File names and paths
- Tags and tag hierarchy
- Frontmatter metadata
- Visible JSON Canvas node and edge text
- Optional semantic chunks when an embedding provider is configured

## How to open it

- Use the search sidebar command or ribbon entry.
- Start from selected text with the search-selected-text command.
- Keep search pinned in the left sidebar when you are triaging many notes.

## Useful query habits

- Use short words first, then narrow the query.
- Search by `path:` or `file:` when you know where a note lives.
- Search by tags or properties when the vault uses consistent metadata.
- Use match-case when capitalization matters.

Search groups results by file and includes snippets so you can jump directly to
the right note, task, or canvas item.
