---
title: Word documents
description: View and embed Word documents in a vault.
---

The DOCX plugin renders `.docx` Word documents inside Lapis. It supports document viewing and embedding; it does not promise a full Microsoft Word editing workflow.

## Open a document

Place a `.docx` file in the vault and open it with the plugin enabled. The **Open Word** command provides another entry point when available in your host. Use the rendered view to read the document beside your notes.

Keep the original file if you need to continue editing in Word or another compatible editor. Conversion and layout fidelity depend on the document's content; review complex documents in their original editor before sharing them.

The plugin can also provide a rendered document in supported embeds. Availability depends on the installed package and host's editor associations.

## Source and availability
