title: Word Count
description: See document word, character and reading estimates.
---

Word Count adds words, characters and an estimated reading time to the workspace status bar for the current document.

## Check a note's length

Enable the plugin and open a supported text note. Read the status-bar count while editing, and check the plugin settings for available display options. If the status bar is hidden by the workspace layout, reveal it before looking for the indicator.

Reading time is an estimate rather than a measurement of a particular reader. Counts can differ from another editor because editors treat formatting and text boundaries differently.

The indicator describes the active document; it is not a vault-wide writing report.
