The PDF plugin opens PDF files in a dedicated viewer and supports PDF embeds in
Markdown surfaces.

This is an optional plugin surface. Confirm it is installed and compatible with your host; see the [owning source](https://github.com/lapismd/lapis-plugins/tree/main/packages/pdf).

## Use PDFs in a vault

1. Add the PDF file to the vault.
2. Open it from the file explorer, or embed it from a note.
3. Keep notes and links around the PDF so the file has context.

## What the plugin provides

- A dedicated PDF viewer for `.pdf` files
- PDF embeds inside notes
- First-party view chrome that matches the rest of the workspace

PDF chrome is owned by the plugin and follows the same dark surface, hairline,
and muted-text style as other first-party views.
