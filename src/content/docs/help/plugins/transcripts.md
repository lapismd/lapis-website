Transcripts presents speaker-separated Markdown in a focused reader with reading controls and comments.

## Read a transcript

Open a supported transcript note and choose **Open transcript** when the command is available. Use the reader to follow speakers and review the text; use its comment controls to keep observations beside the transcript.

Keep the underlying Markdown file as the portable source. Available transcript formatting and reading controls depend on the plugin version and the host's editor associations.

This plugin is a transcript reader. It does not itself establish an audio recording or speech-to-text service. Create or import transcript text using a separate workflow before opening it here.
