---
title: Rename & move
description: Organize files and folders in your vault.
---

You can rename and move notes from the file explorer or from file actions in the workspace.

## Rename a note

1. Open the file explorer.
2. Use the file context menu.
3. Choose rename and enter the new name.

Lapis keeps the vault indexed after the rename so search, graph, and plugin views can update.

## Move a note

Move a note when its folder should carry meaning, for example `Projects/` or `Journal/`. Links are strongest when they use note identity rather than folder position, so avoid moving files only to create hierarchy. Use links and bases for most organization.
