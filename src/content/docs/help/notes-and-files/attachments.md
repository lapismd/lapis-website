---
title: Attachments
description: Embed images and other files in notes.
---

Attachments are files stored inside your vault and linked from notes or canvas boards.

## Add an attachment

Copy or drag a supported file into the vault, then link or embed it from a note.

```markdown
![Design sketch](attachments/sketch.png)
```

You can also use wiki-style embeds when the file is in the vault:

```markdown
![[sketch.png]]
```

## Keep attachments portable

Prefer relative paths and keep related attachments near the notes that use them. When moving a folder, move its local attachments with it.
