---
title: Offline use
description: Keep local notes available without a network.
---

The Desktop preview reads and writes an admitted local vault folder. Ordinary local editing does not require a hosted account, but the folder and application must remain available.

## Features that need a connection

Plugin and package downloads, remote content, external AI providers, optional model downloads, and configured repository backup can need network access. Cached or local providers have their own requirements.

## Browser vaults

The separate web app uses browser-managed storage. Offline use depends on the deployed version, cached assets, and retained vault data. Keep backups and test the workflows you need before relying on offline access.
