The Tauri Desktop preview opens local vault folders. Editing, Search, and Graph use the current Notes packages; Canvas, Bases, Tasks, and Notebook support depends on the installed plugins and host.

## Start here

1. [Open the app](/help/getting-started/download-and-install/).
2. [Create or open a vault](/help/getting-started/create-a-vault/).
3. [Create your first note](/help/getting-started/first-note/).
4. [Link notes together](/help/getting-started/link-notes/).
5. Enable the core plugins that fit your workflow from [Settings](/help/user-interface/settings/).

## Common workflows

- Use [Markdown basics](/help/editing/markdown-basics/) to start, then move through the Editing section for links, embeds, properties, callouts, tables, math, and diagrams.
- Use [Search](/help/plugins/search/) when you know words, paths, tags, or properties.
- Use [Graph view](/help/plugins/graph-view/) when you want to inspect relationships.
- Use [Canvas](/help/plugins/canvas/) when spatial layout matters more than document order.
- Use [Bases](/help/plugins/bases/) and [Tasks](/help/plugins/tasks/) when notes need structured views.
- Use [Workspace layout](/help/user-interface/workspace-layout/) and [Keyboard shortcuts](/help/user-interface/keyboard-shortcuts/) to make repeated work faster.
