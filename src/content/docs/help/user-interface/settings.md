---
title: Settings
description: Configure appearance, editor, and plugins.
---

Settings are split between app-wide preferences and plugin-specific configuration.

## Core areas

- **Editor and views**: control how notes open and how editing surfaces behave.
- **Core plugins**: review the features included by your current host profile. Search and Graph are core examples; optional plugins have their own installation and compatibility requirements.
- **Community plugins**: manage installed plugins, safe mode, and trust decisions.
- **Plugin settings**: configure each enabled plugin's own options.

Prefer changing settings through the app. Editing plugin data files by hand can leave a plugin with invalid saved state.
