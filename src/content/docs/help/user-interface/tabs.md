description: Work with multiple notes open at once.
---

Tabs let you keep several notes, canvases, bases, graphs, or plugin views open in the same workspace.

## Open more than one view

Use file explorer clicks, command palette commands, or plugin actions to open new leaves. Lapis records view history so plugin views such as graph and canvas can return after reload.

## Keep tabs useful

- Keep reference notes beside the note you are writing.
- Open graph or search in a side area while editing in the center.
- Close stale tabs when a workflow is finished.

## Split workspaces

Split tabs when comparison matters: source note beside summary note, base beside note list, notebook beside data source, or canvas beside project brief. Use sidebars for supporting context and tab groups for primary work.
