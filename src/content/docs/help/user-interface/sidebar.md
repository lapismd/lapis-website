The sidebars hold navigation and plugin tools while the center workspace stays focused on notes and views.

## Common sidebar views

- File explorer for vault files.
- Search for vault-wide queries.
- Graph, [notebook Dependencies and Packages](/help/plugins/notebook/panels-and-packages/), and other installed plugin panels.
- Settings and diagnostics surfaces when enabled by the current runtime.

Open a sidebar view from the ribbon, command palette, or plugin command. You can collapse sidebars when you need more editor space.

## Move work out of the note

Sidebars are best for views that help the active note but should not become part of the note body: file navigation, search results, backlinks, outline, graph controls, [notebook session panels](/help/plugins/notebook/panels-and-packages/), and diagnostics.

If a sidebar view starts becoming the main artifact, open it as a normal workspace tab instead.
