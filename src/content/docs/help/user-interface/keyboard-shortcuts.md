Keyboard shortcuts run commands without opening the command palette first.

## How shortcuts work

Commands can declare default hotkeys. The app resolves the active keybinding against the current context, then runs the matching command. If multiple commands want the same shortcut, the command whose context matches the active view wins.

## Common shortcut workflows

- Open the command palette.
- Toggle sidebars.
- Open Search.
- Create a new note.
- Split or focus editor groups.
- Run plugin commands such as opening Graph, Canvas, or Notebook views when their plugins are available.

Use settings to review and change shortcuts when a default conflicts with your browser, operating system, or desktop window manager.
