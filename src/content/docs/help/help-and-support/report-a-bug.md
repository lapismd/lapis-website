---
title: Report a bug
description: How to file useful bug reports.
---

Good bug reports include enough context to reproduce the problem.

## Include

- Runtime: web/PWA or desktop.
- Browser and operating system, or desktop app version.
- Vault type: browser vault or filesystem folder.
- Steps to reproduce.
- What you expected to happen.
- What happened instead.
- Any relevant console errors or plugin failure messages.

Avoid sharing private notes. If a note triggers the issue, reduce it to a small example first.

Report application problems in [lapis-desktop](https://github.com/lapismd/lapis-desktop/issues).
Report site, documentation, and broken-link problems in [lapis-website](https://github.com/lapismd/lapis-website/issues).
For an isolated plugin problem, use that plugin's owning repository and include its version.
