## Are my notes normal files?

Desktop vaults are normal folders. Browser vaults are stored in browser-managed storage, but notes still use portable formats such as Markdown, JSON Canvas, and `.base` documents.

## Is Lapis Notes an Obsidian clone?

No. Lapis uses many familiar local-first note-app concepts, but its runtime, plugin boundary, notebook work, and host-specific behavior are its own.

## Can I use Obsidian plugins?

Some Obsidian-style plugin package conventions are supported, but plugins should be tested in Lapis before you rely on them. Safe mode and workspace trust exist to keep powerful plugin behavior explicit.

## Does the web app work offline?

Offline browser use depends on the deployed version, cached application assets, and retained local vault storage. Network-backed features still need a connection.
