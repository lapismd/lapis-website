A vault is the folder or browser-local workspace where Lapis Notes stores your notes, canvas files, plugin data, and generated app state.

## Create a new vault

1. Open Lapis Notes.
2. Choose the create-vault option in the vault chooser.
3. Give the vault a short, durable name.
4. On desktop, choose the folder location. In the web app, Lapis creates a browser vault in browser-managed storage.

## Open an existing vault

Use this when you already have a folder of Markdown files or a vault copied from another app.

1. Choose the open-vault option.
2. Select the folder that contains your notes.
3. Wait for metadata, links, search, and plugin indexes to finish building.

## What belongs in a vault

Keep Markdown notes, attachments, `.canvas` boards, `.base` files, and notebook files in the vault. Generated plugin data lives beside the vault state so plugins can rebuild views without changing your source notes unless you explicitly edit them.
