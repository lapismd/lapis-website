---
title: Link notes
description: Connect ideas with wikilinks and backlinks.
---

Use internal links to connect related notes without moving them into one large document.

## Create an internal link

Type a note name inside double brackets:

```markdown
See [[Project brief]] for the current scope.
```

If the target note does not exist yet, Lapis can still track the unresolved link so you can create the note later.

## Use links as structure

- Link meeting notes to the project they affect.
- Link tasks to the decision or source note that explains them.
- Link index notes to groups of related pages.

Backlinks and graph views are built from these links, so a small habit of linking makes the rest of the workspace more useful.
