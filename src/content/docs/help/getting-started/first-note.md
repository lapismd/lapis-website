title: First note
description: Create and save your first Markdown note.
---

Notes are Markdown files. They are readable outside Lapis Notes and can use ordinary Markdown syntax plus Lapis features such as links, properties, callouts, and task-note widgets.

## Create a note

1. Open a vault.
2. Use the new-note command, file explorer action, or command palette.
3. Enter a name such as `Research plan`.
4. Start writing in the editor.

## Add useful structure

Use headings for sections, lists for ideas, and links for relationships:

```markdown
# Research plan

Related: [[Project brief]]

## Questions

- What do we already know?
- What should become a task?
```

Use reading mode when you want the note rendered cleanly, and source mode when you want direct Markdown editing.
